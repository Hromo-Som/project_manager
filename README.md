# 📚 Изучение SQLAlchemy: Менеджер проектов

Этот репозиторий — моя учебная песочница для изучения **SQLAlchemy** (Core и ORM).  
Здесь я экспериментирую с созданием таблиц, написанием запросов, связями и миграциями на примере простого приложения для управления проектами и задачами.

---

## 🗂️ Структура проекта

```plaintext
project_manager/
├── app/
│   ├── __init__.py
│   │
│   ├── database/               # Инфраструктура БД
│   │   ├── __init__.py
│   │   ├── config.py           # Строки подключения (DATABASE_URL)
│   │   ├── engine.py           # Движок SQLAlchemy (sync / async)
│   │   ├── metadata.py         # Реестр описаний таблиц
│   │   └── tables.py           # Описание таблиц
│   │
│   ├── models/                 # SQLAlchemy ORM-модели
│   │   ├── __init__.py
│   │   └── base.py             # Базовый класс (DeclarativeBase)
│   │
│   ├── schemas/                # Pydantic-схемы (валидация, сериализация)
│   │   └── __init__.py
│   │
│   ├── create_tables.py        # Модуль для создания таблиц
│   └── main.py                 # Точка входа FastAPI (подключение роутеров)
│
├── tests/                      # Тесты (pytest)
│   └── __init__.py
│
├── .gitignore
├── requirements.txt
├── project_manajer.db          # База дынных (SQLite)
└── README.md
```

## 📚 Что я планирую изучить в этом проекте

Я последовательно разбираю следующие темы:

| № | Тема | Описание |
|---|------|----------|
| 1 | Декларативный стиль ORM | Модели, ограничения, типы колонок, индексы |
| 2 | Миграции баз данных | Настройка Alembic, генерация и применение миграций |
| 3 | Session, Unit of Work и CRUD | Жизненный цикл сессии, паттерн Unit of Work, базовые CRUD-операции |
| 4 | Фильтрация, сортировка, агрегация и JOIN | `filter()`, `order_by()`, `group_by()`, `join()`, `subquery()` |
| 5 | Relationships, каскады и стратегии загрузки | `lazy='joined'`, `lazy='selectin'`, `cascade`, `delete-orphan` |
| 6 | Асинхронный SQLAlchemy | `AsyncSession`, `asyncpg`, асинхронные CRUD-операции |
| 7 | Обработка ошибок и управление сессиями | Транзакции, откаты, повторные попытки, `session.begin()` |
| 8 | Безопасность, конфигурирование и профилирование | SQL-инъекции, настройка пула соединений, профилирование запросов |

Каждая тема будет закреплена практическим кодом в этом репозитории.
